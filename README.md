# impactors

Some musings on the small asteroids that frequently impact Earth and other planets.

The first item is a comparison of the 13 asteroids discovered in space before they
entered Earth's atmosphere, from 2008 TC3 to 2026 RW1 (posted to the NEO Confirmation
Page as CERNQ52 and discovered by the Catalina Sky Survey at Mount Lemmon, G96, on
2026 September 6). The report ranks them by in-flight confidence (observations,
contributing telescopes, advance notice, orbit uncertainty parameter U) and separately
by the strength of post-impact confirmation (meteorites, sensors, cameras, witnesses).

A second report, `report/impact-comparative-analysis.md`, goes beyond the ranking: the
circumstances and published science behind each of the 13, what the set implies about the
objects versus about our detection and confirmation infrastructure, and how it compares to
impacts on other planets and moons (Shoemaker-Levy 9 on Jupiter, Jupiter's amateur-detected
fireballs, lunar impact flashes, Mars) and to Earth impacts with no advance detection
(Chelyabinsk, Tunguska, Sikhote-Alin, Carancas, Benešov).

## Contents

- `report/impactor-confidence-report.md` — the ranking report (Markdown source)
- `report/impactor-confidence-report.pdf` — the same, A4 landscape
- `report/impact-comparative-analysis.md` — circumstances, science, patterns, and cross-body comparison
- `report/impact-comparative-analysis.pdf` — the same, A4 landscape
- `report/table.md` — the ranking table alone, as generated by `scripts/rank.py`
- `report/report.css` — stylesheet used for the HTML/PDF build
- `data/mpc_observations.json` — per-object observation counts and station codes from the
  MPC Explorer API (fetched 2026-09-07)
- `data/sbdb_orbits.txt` — orbits, observation counts, and U from the JPL Small-Body Database
- `data/cneos_fireballs.txt` — CNEOS fireball database (US government sensor) entries on each impact date
- `data/ranking.json` — the computed in-flight ranking with its rank-sum components
- `data/impactors/*.json` — one rich dossier per pre-impact discovery (discovery/impact
  circumstances, orbit, physical parameters, confirmation evidence, scientific results,
  papers, sources); schema documented in `impact-comparative-analysis.md`
- `data/comparisons/*.json` — dossiers on comparison events: impacts on other planets/moons
  (`planetary-impacts.json`) and undetected/historical Earth impacts (`earth-undetected.json`),
  plus sourced notes on planetary-defense policy history (`notes.md`)
- `scripts/mpc_obs.py` — fetch and count MPC observations
- `scripts/sbdb_orbits.py` — query the JPL SBDB
- `scripts/fireballs.sh` — query the CNEOS fireball API
- `scripts/rank.py` — compute the ranking and emit the table
- `scripts/build_report.sh` — build HTML and PDF from a Markdown report (needs pandoc and Chrome)

## Reproducing

Run from the repo root with Python 3 (standard library only):

```
python3 scripts/mpc_obs.py
python3 scripts/sbdb_orbits.py > data/sbdb_orbits.txt
bash scripts/fireballs.sh > data/cneos_fireballs.txt
python3 scripts/rank.py
bash scripts/build_report.sh
```
